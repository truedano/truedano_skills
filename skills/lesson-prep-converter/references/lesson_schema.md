# 教案結構化 Markdown 規範 (Lesson Plan Schema)

為了確保轉換後的教案能讓 AI 最佳理解，並能無痛轉換為 PPT、Word、教材網頁，所有檔案必須統一遵循以下規範。

---

## 1. 檔案命名與目錄組織

```text
<輸出目錄>/
├── metadata.json           # 整批檔案的轉換清單與目錄索引
├── images/                 # 提取出的圖檔或原始掃描圖
│   ├── lesson01_fig01.png
│   └── ...
├── 01_單元名稱.md           # 結構化 Markdown 教案
└── 02_單元名稱.md
```

- 檔名使用流水號或主題名稱，避免特殊字元與過長路徑。
- 相關圖片一律放入同層級或相對路徑 `images/`。

---

## 2. YAML Frontmatter 元數據規格

每個 `.md` 檔案頂部必須包含標準 YAML 區塊：

```yaml
---
title: "單元或主題完整名稱"
subject: "學科領域 (例: 物理 / 數學 / 歷史)"
grade: "適用年級 (例: 國八 / 高一 / 國小五年級)"
duration_minutes: 45
difficulty: "基礎 | 進階 | 挑戰"
learning_objectives:
  - "教學目標 1 (具體行為動詞，例：能指出...)"
  - "教學目標 2 (例：能解釋...)"
core_concepts:
  - "核心概念詞彙 1"
  - "核心概念詞彙 2"
source_files:
  - "原始來源檔案名稱.pdf (頁碼: 12-15)"
assets:
  - id: "fig-1"
    file: "images/fig_01.png"
    caption: "圖表說明"
---
```

## 4. 下游轉換適配規則 (Target Mapping Rules)

1. **轉 PPT (如 Marp / PowerPoint)**：
   - 每個 `##` 或 `###` 自動對應為投影片分頁。
   - 內文的條列點 (Bullet points) 控制在 3-4 點以內，不超過兩行，方便自動轉換投影片版面。
2. **轉 Word (如 Pandoc / 講義)**：
   - YAML 的 `title` 自動映射為文件封面與主標題。
   - `[!NOTE]`, `[!TIP]` 會映射為引用呼應方塊 (Callout Box)。
3. **轉 網頁 (如 VitePress / Docusaurus)**：
   - 前置 YAML 自動成為頁面 Meta 標籤與側邊欄導航資訊。
   - 支援完整標準 Markdown 與 LaTeX 數學語法。
