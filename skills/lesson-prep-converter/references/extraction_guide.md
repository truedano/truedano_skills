# 多格式提取與處理策略手冊 (Format Extraction Guide)

本手冊定義當輸入目錄包含不同副檔名時的萃取與轉換策略。

---

## 1. 文字與表格格式

### 純文字 (`.txt`, `.md`)
- **策略**：直接讀取原始內容。
- **處理重點**：檢查編碼（UTF-8 / Big5），去除無意義空行與重複分行符號。

### 表格資料 (`.csv`, `.tsv`)
- **策略**：
  - 如果是成績單、數據表：轉換為標準 Markdown 表格。
  - 如果是教案條目、題目題庫（欄位包含：題號、題目、選項、解答）：轉化為對應單元的結構化問答段落。

### 試算表 (`.xlsx`, `.xls`)
- **策略**：
  - 若安裝有 Python 可用 `openpyxl` / `pandas`；若在 Node.js 環境可透過腳本解析工作表。
  - 每個工作表 (Sheet) 獨立標註，保留表頭結構並轉為 Markdown 語法。

---

## 2. 文書與簡報格式

### Word 文件 (`.docx`)
- **特點**：通常已包含完整教案架構、章節、評量題目。
- **萃取方式**：
  - 首選：使用 `pandoc input.docx -o intermediate.md`。
  - 備選（無 pandoc 時）：解開 docx (本質為 zip)，提取 `word/document.xml` 解析段落與表格，並將 `word/media/` 中的圖檔解壓至目標 `images/` 目錄。
- **結構重整**：將解析出來的雜亂標題與清單，依據 `lesson_schema.md` 重新校準標題階層。

### 簡報文件 (`.pptx`)
- **特點**：內容呈片斷式、短句多、脈絡分散。
- **萃取方式**：
  - 解壓提取每頁投影片 XML (`ppt/slides/slide*.xml`) 與備忘稿 (`ppt/notesSlides/*.xml`)。
  - 將每張投影片的標題、內文、演講者備忘稿 (Speaker Notes) 整理出來。
  - 提取 `ppt/media/` 圖片存至 `images/`。
- **結構重整**：**簡報最常缺少教學目標與脈絡**，重整時必須由 AI 將片斷投影片串聯成連貫的「引導 -> 概念說明 -> 討論 -> 總結」教案。

---

## 3. PDF 與影像掃描檔

### 原生電子 PDF (`.pdf` 含向量文字)
- **萃取方式**：
  - 優先讀取文字層。
  - 提取文件中內嵌的圖表。
  - 辨識頁首、頁尾、頁碼等無用資訊並進行過濾。

### 掃描版 PDF 與掃描圖檔 (`.pdf`, `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`)
- **特點**：書本掃描、講義拍照。常見問題包括版面傾斜、手寫筆記、雙欄排版、印刷雜訊。
- **萃取方式**：
  - **切勿依賴傳統簡易 OCR**。
  - **多模態視覺辨識**：直接交由多模態模型（如 Gemini / Claude / GPT-4o 視覺功能）分批次讀取圖片。
  - **排版順序還原**：特別注意雙欄書籍掃描，須指示依「由左至右、由上至下」之正常閱讀順序展開，切勿水平橫向截斷跨欄。
  - **圖表另存**：重要教學示意圖、實驗步驟圖保留於 `images/`，並在 Markdown 中保留插入錨點 `![說明](images/xxx.png)`。
